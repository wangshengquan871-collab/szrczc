# 苏州人才政策综合展示网站

首页：`index.html`。原站已经接入Node.js + Express + MySQL登录保护，必须通过上一级目录的`server.js`访问。页面、政策数据、原资源和下载文件保留原有相对位置。

## 运行

1. 在终端进入上一级`全市政策`目录。本机MySQL和被忽略的`.env`已配置完成。
2. 执行`npm start`；Node不在PATH时，可使用工作区便携Node：

   ```powershell
   cd 'C:\Users\11811\Desktop\网页\政策\全市政策'
   & '..\.tools\node-v24.21.0-win-x64\node.exe' server.js
   ```

3. 访问`http://localhost:3000/`。未登录跳转`/login`；通过`/register`注册后登录，进入原来的`/index.html`。
4. 顶部导航右侧提供用户中心，显示真实用户名；点击可查看注册时间、进入我的账号或退出登录。页面底部账户入口继续可用。退出后再次访问原页面需重新登录。首次在其他电脑安装、初始化数据库及生产HTTPS配置见上一级README。

详情页的导览、搜索和图表需要启用JavaScript；首页的静态内容与链接在关闭JavaScript时仍可使用。页面、脚本、JSON、图片和11份Word/Excel均由服务端验证Session后提供；认证页面仅公开自身需要的指定素材。原HTML和政策资料未改写；共享导航CSS/JS新增用户中心，服务端在响应中保留底部账户操作区。

用户中心从`GET /api/auth/me`取得`username`和MySQL注册时间`createdAt`，没有预置账号或虚构日期。下拉菜单支持键盘、点击外部及焦点移出关闭；移动端显示图标与截断用户名，完整用户名可在菜单查看。顶部退出携带CSRF Token调用真实`POST /api/auth/logout`，成功后进入`/login`。服务端禁用缓存并拒绝旧Cookie，历史返回重新验证会话。

Live Server、其他静态服务器及双击HTML不经过Express身份验证，不可用于正式访问或发布。生产代理不得直接托管本目录。文件白名单不提供本说明、source-manifest、认证HTML副本或后端配置；只有具备本机文件读取权限的人能直接读取磁盘文件。

### 数据与比较规则

- 金额预览直接读取现有 `pages/政策对比资源/policy-data.js`，使用原52条记录编号、同口径视图和排序规则。首页不加载约2.3MB的原始工作簿快照，完整原表仍在既有对比页查阅。
- 区间图的淡金／松绿端点分别表示明确最低／最高金额；空心圆标示原表明确列出的中间档次。离散档次用虚线连接，不能理解为区间内任意金额可获批。仅列上限时不补最低值；真实零保留；缺失值不按零排名。
- 排序柱状图在同一刻度上绘制最低与最高两条柱。图表明确显示单位、类别、资金性质、原始档次、资料边界及原表定位；不合计财政经费、住房、贷款或投资。
- 范围仅为Excel中的八个地区，市级姑苏领军不混入八地金额比较。常熟常规资金缺失、园区创新综合补贴与重大创业、高新区顶尖团队、吴中住房分档冲突继续按原对比数据处理。
- 比较篮允许2–4地，并按原表地区顺序展示。过滤卡片不会移除所选地区；达到4地后禁用新增，移除一个可更换。页面在当前浏览器会话内保留选择，存储被禁用时仍可正常比较。
- 首页图表出处链接会带入图表类别并定位原始Excel单元格；卡片、图表行及比较篮均提供详情快捷入口。
- 类别筛选来自原页面项目类别，不能将园区重大创业当作独立团队类别。来源年份是办法、通知或专题资料年份，不代表当前开放批次或更新时间。筛选结果不代替申报资格审核。

### 元数据与本地打开

`data/portal-data.json` 是统一元数据文件。首页内嵌同一JSON的只读副本，支持双击本地HTML时使用筛选与比较篮，避免本地文件的fetch限制。两份内容由工作区 `.checks/prepare-home-data.cjs` 同步生成并验证一致；元数据留存对应源文件及字段定位。金额没有复制到新增JSON，仍由原对比数据维护。

以后调整原政策资料时，应重新核对来源年份／类别映射，再运行生成工具更新JSON与首页元数据，并完成来源与交互检查。该生成工具及`.checks`仅用于开发验收，网站运行无需这些文件。
